## 📌 About This Repository

This repository documents my learning journey through the **IBM Machine Learning Professional Certificate**.

I created this repository to organize, practice, and showcase the knowledge and practical skills I develop throughout the program.

It will contain the **labs, notebooks, exercises, experiments, and projects** completed during the different courses of the specialization.

The goal is not only to complete the certificate, but to build a strong practical foundation in **Machine Learning, Data Science, and Artificial Intelligence** through hands-on work.

Through this learning journey, I aim to:

* Strengthen my foundations in **Machine Learning**
